# Spec Delta

## Purpose

Предоставляет многоступенчатую систему упражнений разных типов внутри каждого урока для максимальной вовлеченности и предотвращения когнитивной усталости.

## ADDED Requirements

### Requirement: Multi-stage drill types
Система SHALL поддерживать минимум 4 типа упражнений в рамках одного урока: `vocab`, `slotSubstitution`, `listening`, `speech`.

#### Scenario: User navigates through diverse drill types
- **WHEN** пользователь проходит шаги дневного урока
- **THEN** система отображает специализированный интерфейс для текущего типа упражнения (словарная карточка, подстановка в каркас, скрытое аудирование или речевой дрил)

### Requirement: Listening comprehension with hidden text
Система SHALL позволять скрывать текст фразы в упражнениях типа `listening`, воспроизводить качественное аудио и требовать повторения эхом.

#### Scenario: User practices listening drill
- **WHEN** открывается шаг типа `listening`
- **THEN** текст на казахском скрыт за маской, проигрывается чистый звук через синтезатор речи, а кнопка раскрытия доступна по запросу
