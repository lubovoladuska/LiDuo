# Design

## Context

См. `proposal.md`. В текущей версии все шаги урока визуально и функционально одинаковы (однотипный речевой ввод). Необходимо добавить вариативность практик и расширить словарный банк до 8–12 активных слов на урок.

## Goals / Non-Goals

**Goals:**
- Ввести перечисление `DrillType` (`vocab`, `slotSubstitution`, `listening`, `speech`) с полной обратной совместимостью (дефолт `speech`).
- Ввести модель `VocabItem` и поддержать расширенный список слов в `DayLesson`.
- Обновить `DrillScreen` для адаптивной визуализации каждого типа практики.
- Обогатить `week_01.json` лексикой и упражнениями разных типов для всех 7 дней.
- Добавить режимы «Словарный спринт» и «Подстановочный тренажер» в `PracticeScreen`.

**Non-Goals:**
- Замена микрофонного ввода на кликанье или сборку слов из кубиков (говорение вслух остается главным критерием прохождения).
- Изменение SQLite схемы (все дрилы продолжают фиксироваться в `drill_history`).

## Decisions

1. **Единый экран `DrillScreen` с адаптивными компонентами**:
   - *Решение*: Использовать единый сессионный контроллер `DrillSessionProvider`, где центральный виджет `_buildDrillContent()` динамически отображает:
     - Для `vocab`: визуальную карточку слова с транскрипцией, контекстным примером и авто-озвучкой.
     - Для `slotSubstitution`: формулу с визуально акцентированным цветным слотом переменной.
     - Для `listening`: аудиоплеер с маскированным текстом до попытки распознавания.
     - Для `speech`: коммуникативное задание.
   - *Альтернатива*: Делать 4 разных экрана. Отклонено из-за дублирования логики сессии, навигации и автосохранения.

2. **Обратная совместимость**:
   - `AudioDrill.fromJson` использует безопасный парсинг `type` со значением по умолчанию `DrillType.speech`.

## Risks / Trade-offs

- [Риск]: Увеличение когнитивной нагрузки на пользователя из-за смены форматов внутри одного занятия → [Митигация]: Четкие бейджи этапов (например: «1/4 Сөздік заряд», «2/4 Подстановки», «3/4 Аудирование», «4/4 Сөйлеу») для понятной предсказуемой траектории.
