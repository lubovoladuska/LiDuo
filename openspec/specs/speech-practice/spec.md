# speech-practice Specification

## Purpose
Предоставляет отдельный автономный тренажер свободной речевой практики для закрепления изученных фраз и отработки ошибок в любое время.

## Requirements

### Requirement: Cross-lesson speech workout
Система SHALL позволять пользователю запускать свободную сессию практики по пройденным урокам.

#### Scenario: User starts quick workout
- **WHEN** пользователь выбирает режим «Экспресс-тренажер» на экране практики
- **THEN** система формирует случайную выборку из ранее пройденных речевых дрилов и запускает сессию говорения

### Requirement: Mistake review workout
Система SHALL сохранять фразы с низкой точностью произношения (<80%) и предоставлять режим работы над ошибками.

#### Scenario: User practices weak drills
- **WHEN** пользователь открывает раздел «Работа над ошибками»
- **THEN** система загружает список фраз, вызвавших затруднения, для повторной отработки с микрофоном
