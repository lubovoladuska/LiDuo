# vocab-matrix Specification

## Purpose
Предоставляет инструменты расширения активного словарного запаса (8–12 слов на урок) и скоростной тренировки подстановки слов в грамматические слоты.

## Requirements

### Requirement: Structured vocabulary primer
Каждый урок программы SHALL содержать структурированный список из не менее 8 ключевых слов с переводом, транскрипцией и аудио.

#### Scenario: User reviews vocabulary primer
- **WHEN** пользователь начинает шаг типа `vocab`
- **THEN** система отображает слово на казахском, перевод, пример использования и кнопку мгновенного прослушивания

### Requirement: Slot substitution matrix training
Система SHALL предоставлять возможность отработки быстрой подстановки переменных слов в грамматические каркасы в Центре практики.

#### Scenario: User runs slot substitution workout
- **WHEN** пользователь выбирает режим «Подстановочный тренажер» в Центре практики
- **THEN** система генерирует серию упражнений с фиксированным грамматическим каркасом и сменяемыми лексическими слотами
