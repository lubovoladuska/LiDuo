# 🇰🇿 LiDuo — 90 Күнде Еркін Сөйлеу (Fluent Kazakh in 90 Days)

**LiDuo** — бескомпромиссно эффективная, открытая (Open Source) и автономная (100% Offline-First) система для форсированного овладения разговорной речью на казахском языке за 60–90 дней.

В отличие от развлекательных приложений вроде Duolingo, LiDuo не тратит ваше время на клики по кубикам слов. **70% времени в LiDuo вы говорите вслух в микрофон**, отрабатывая 1500 ключевых речевых паттернов и чанков, покрывающих 85% повседневной казахской речи.

---

## ⚡ Ключевые принципы

1. **Речевая активация (Spoken Active Production)**: Упор на речедвигательный аппарат. Каждое упражнение — это вызов: «Услышь / Прочитай задачу -> Скажи правильную форму вслух на казахском -> Получи моментальную оценку».
2. **Матрица 1500 чанков и формул**: Никаких абстрактных грамматических таблиц. Грамматика (сингармонизм, агглютинация, падежи) изучается исключительно через работающие речевые шаблоны («Маған ... керек», «... бар ма?», «... барғым келеді»).
3. **100% Offline-First**: База всех 90 дней уроков, аудио-дрилов, формул и интервальное повторение (SRS на базе SuperMemo SM-2) хранятся локально в SQLite. Приложение полноценно работает в самолете и степи.
4. **Степной модерн (Nomad Luxe)**: Премиальный, сосредоточенный дизайн в традициях [LiReader](https://github.com/lubovoladuska/LiReader) (глубокий графит, благородное золото, индиго и бирюза). Ноль навязчивой рекламы, подписок и детских мультяшных маскотов.
5. **Модульная архитектура (Course Packs)**: Ядро приложения полностью языконезависимо. Новые языки и диалекты подключаются как открытые JSON-пакеты.

## 📅 Программа 12 спринтов (90 Дней)

- **Фаза I (Недели 1–4): Фундамент и Падежи (A0 -> A1)**
  - Неделя 1: Звуки (`ә, і, ң, ғ, ү, ұ, қ, ө, h`), сингармонизм и связки сказуемости (`-мын/-сіз`).
  - Неделя 2: Множественность (`-лар/-лер`) и притяжательность (`менің ...-ым`, `бар / жоқ`).
  - Неделя 3: Падежи действия (Барыс `-ға/-ге`, Табыс `-ны/-ні`, Жатыс `-да/-де`).
  - Неделя 4: Падежи исхода и совместности (Шығыс `-дан/-ден`, Көмектес `-мен/-пен`).
- **Фаза II (Недели 5–8): Времена и Реальная жизнь (A1 -> A2)**
  - Неделя 5: Настоящее и будущее время (`-а/-е/-й`, глаголы `отыр/тұр/жатыр/жүр`).
  - Неделя 6: Прошедшее время (`-ды/-ді`) и желания (`-ғым келеді`, `керек/қажет`).
  - Неделя 7: Городские сценарии: такси, рынок/базар, ресторан, магазин.
  - Неделя 8: Деловые сценарии: банк, ЦОН, поликлиника, самочувствие.
- **Фаза III (Недели 9–12): Спонтанность и Глубина (A2 -> B1/B2)**
  - Неделя 9: Модальность возможности (`-а аламын`, `болады / болмайды`).
  - Неделя 10: Оттенки глаголов (`-п көру`, `-п қою`, `-п жіберу`, `-п тастау`).
  - Неделя 11: Условия (`-са/-се`) и логические союзы (`өйткені`, `сондықтан`).
  - Неделя 12: Свободная спонтанная речь, идиомы и финальный экзамен.

## 🛠️ Стек технологий

- **Фреймворк**: [Flutter](https://flutter.dev) (Dart 3.x)
- **Платформы**: Android, Windows Desktop, iOS
- **Хранение данных**: `sqflite` (SQLite), `shared_preferences`
- **Аудио и Речь**: `flutter_tts`, `speech_to_text`, `audioplayers`
- **Интервальное повторение**: Алгоритм SuperMemo SM-2
- **ИИ-модуль (Опциональный BYOK)**: `google_generative_ai` (Gemini Flash для свободных ролевых диалогов)

## 🚀 Сборка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/lubovoladuska/LiDuo.git
cd LiDuo

# Установка зависимостей
flutter pub get

# Проверка анализатора кода
dart analyze lib test

# Запуск тестов
flutter test

# Запуск приложения на устройстве
flutter run
```
